waybill-arc pauses the supervisor while it waits for supplier replies. Two inbound webhook endpoints resume the run when replies arrive: one for the supplier gateway, and one for Vapi voice and SMS events. This guide covers how each webhook works, what payloads to expect, and how to configure them.

## Acknowledgement and background processing

The supplier gateway (`POST /webhook`), AgentMail email (`POST /webhook/email`), WhatsApp, and Vapi call-end (`end-of-call-report`) webhooks acknowledge a reply before the supervisor finishes with it:

1. waybill-arc saves the supplier reply.
2. waybill-arc responds to the sender immediately.
3. waybill-arc resumes the supplier's worker in the background.

Resuming the worker can take a minute or more. Answering first keeps each webhook under the 60-second timeout that relays such as Hookdeck enforce.

A `200` response means the reply was accepted and saved. It does not mean the supervisor has resumed. Supervisor progress shows up shortly afterwards, so poll the request state instead of expecting it to change by the time the webhook returns.

If a background resume fails or is cut off, the reply stays unprocessed. waybill-arc retries unprocessed replies at startup and every 10 minutes. A reply that another process already claimed is retried once that claim expires after 15 minutes. Unprocessed replies have no age limit.

WhatsApp returns `500` if saving the reply fails, so Meta redelivers the message. Vapi SMS (`session.updated`) events still resume the supervisor before the endpoint responds.

## Supplier gateway

`POST /webhook` is called by the supplier gateway when a supplier replies.

**Request body**

```json
{
  "requestID": "299cb5b9-4b9d-4c1a-9d51-3f2f0a4f0e21",
  "supplierID": "SUP-00142"
}
```

`supplierID` is optional. The endpoint returns:

```json
{
  "received": true
}
```

The supervisor run resumes automatically in the background after the endpoint responds. A UI does not need to call this endpoint directly.

## AgentMail email

`POST /webhook/email` receives inbound email replies from AgentMail. The endpoint saves the reply, responds, and then resumes the supervisor in the background.

To register the webhook, run:

```bash
npm run channels:register-webhook -- https://your-host/webhook/email
```

Store the printed secret as `AGENTMAIL_WEBHOOK_SECRET`. AgentMail will sign inbound requests with this secret so the handler can verify them.

## Vapi voice and SMS

`POST /webhook/vapi` receives events from Vapi when a voice call ends or an SMS session is updated.

### Authentication

Vapi echoes back the `x-waybill-signature` header from the `server.headers` set on each transient assistant. The endpoint validates this header against `VAPI_WEBHOOK_SECRET`.

### Request matching

Requests are matched to a `(request_id, supplier_id)` pair through `channel_threads`:

- For `voice`, the match uses the Vapi call ID.
- For `sms`, the match uses the Vapi session ID.

### Event handling

Only two event types are acted on:

- `end-of-call-report`: voice call ended. waybill-arc saves the call report, responds, and resumes the supervisor in the background.
- `session.updated`: SMS session updated. waybill-arc resumes the supervisor before it responds.

### Response codes

| Status | Meaning |
| --- | --- |
| `200 {}` | Event accepted. For `end-of-call-report`, the call report is saved and the supervisor resumes in the background. For `session.updated`, the supervisor was resumed. |
| `204` | Event ignored (unhandled type, unmapped call or session, or nothing new from the supplier) |
| `401` | Invalid webhook signature |
| `503` | Vapi webhook is not configured (`VAPI_WEBHOOK_SECRET` is unset) |

### Failure modes

Failures that happen after a call is dispatched do not arrive as HTTP errors. Instead, they appear as `endedReason` on the `end-of-call-report`:

- unanswered
- voicemail
- insufficient credits
- international dialing blocked (on free Vapi numbers)

Vapi exposes no SMS delivery status. Inbound SMS is US↔US only, so a non-US supplier can receive an SMS but cannot reply through Vapi.
