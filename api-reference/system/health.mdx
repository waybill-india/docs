Use `GET /health` to verify that the waybill-arc server is running and responsive. This is useful for container health checks, local dev verification, and uptime monitoring.

## Request

```bash
curl http://localhost:3001/health
```

## Response

<ResponseField name="status" type="string">
  Always `"ok"` when the server is healthy.
</ResponseField>

```json
{
  "status": "ok"
}
```

## Errors

This endpoint does not return errors under normal circumstances. If the server is unreachable, the connection itself will fail.
