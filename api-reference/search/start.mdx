Initiate the supplier search stage for a resolved intake request. This endpoint selects internal suppliers from your supplier network and hands them off to the supervisor for RFQ dispatch. No request body is required.

Three open-web legs run in parallel with supplier selection. All of them run only when `SUPPLIER_SIMULATOR=false`:

- **Exa web search** (`EXA_API_KEY`) starts an asynchronous run for suppliers on the open web, covering marketplace listings and quotation-based suppliers. Poll [`GET /search/:requestID/web`](/api-reference/search/web) for its results.
- **Marketplace search** (`PARSEBOT_API_KEY`) scrapes Amazon, Flipkart, IndiaMART, and Alibaba for product listings. This leg completes before the response is sent, so you can read [`GET /search/:requestID/marketplaces`](/api-reference/search/marketplaces) immediately.
- **Distributor search** (`DIGIKEY_CLIENT_ID` + `DIGIKEY_CLIENT_SECRET`, `MOUSER_API_KEY`) queries the DigiKey and Mouser catalog APIs for live stock and pricing. This leg also completes before the response is sent, so you can read [`GET /search/:requestID/distributors`](/api-reference/search/distributors) immediately.

## Endpoint

```http
POST /search/:requestID
```

## Request

No request body is needed. Send the `requestID` as a path parameter.

<CodeGroup>

```bash cURL
curl -X POST http://localhost:3001/search/299cb5b9-4b9d-4c1a-9d51-3f2f0a4f0e21 \
  -H "Content-Type: application/json"
```

</CodeGroup>

## Response

### 200 — Internal suppliers found

When internal suppliers are matched, the supervisor receives the handoff and sends RFQs. The response includes the supplier selections, supervisor status, and one boolean flag per open-web leg.

```json
{
  "requestID": "299cb5b9-4b9d-4c1a-9d51-3f2f0a4f0e21",
  "selections": [
    {
      "supplierID": "SUP-00142",
      "description": "…the supplier's own profile from the supplier network…",
      "reasoning": "Franchised distributor explicitly handles STM32…"
    }
  ],
  "supervisor": {
    "status": "awaiting_supplier_responses",
    "waitingFor": ["SUP-00142", "SUP-00187"]
  },
  "webSearchStarted": true,
  "marketplaceSearched": true,
  "distributorsSearched": true
}
```

<ResponseField name="webSearchStarted" type="boolean">
  `true` when the Exa web search run was created. Poll [`GET /search/:requestID/web`](/api-reference/search/web) for candidates.
</ResponseField>

<ResponseField name="marketplaceSearched" type="boolean">
  `true` when marketplace listings were stored. Fetch [`GET /search/:requestID/marketplaces`](/api-reference/search/marketplaces) once. No polling is needed.
</ResponseField>

<ResponseField name="distributorsSearched" type="boolean">
  `true` when distributor offers were stored. Fetch [`GET /search/:requestID/distributors`](/api-reference/search/distributors) once. No polling is needed.
</ResponseField>

Each flag is `false` when that leg is disabled, unconfigured, or failed outright.

### 200 — No internal suppliers matched

When no internal suppliers match but at least one open-web leg produced results, `supervisor` is `null` and no RFQs are sent. Read the open-web legs instead of `/supervisor`.

```json
{
  "requestID": "299cb5b9-4b9d-4c1a-9d51-3f2f0a4f0e21",
  "selections": [],
  "supervisor": null,
  "webSearchStarted": true,
  "marketplaceSearched": true,
  "distributorsSearched": true
}
```

## Errors

| Status | Body | Meaning |
| --- | --- | --- |
| 404 | `{ "error": "Request not found" }` | The `requestID` does not exist. |
| 409 | `{ "error": "Intake is not resolved yet", "status": "awaiting_answer" }` | The intake stage is still asking clarifying questions. Resolve it first. |
| 409 | `{ "error": "Request was already handed off to the supervisor", "status": "…" }` | The request has already been handed off; a second call is not allowed. |
| 422 | `{ "requestID": "299cb5b9-…", "error": "No plausible suppliers found for this part" }` | No internal suppliers matched and no open-web leg produced anything (all legs unconfigured or all failed). This is terminal; show as "no suppliers found." |

## Behavior notes

- A second call after a successful handoff returns **409**.
- After a **no-internal-suppliers 200**, a retry is allowed and reuses the same web search run.
- The open-web legs run only when `SUPPLIER_SIMULATOR=false`. When `SUPPLIER_SIMULATOR=true`, all three flags are `false` and sourcing goes through the supplier simulator instead. See [Environment](/configuration/environment).
