`/webhook/whatsapp` is the Meta WhatsApp Cloud API webhook. Meta calls this endpoint, not you. Point your Meta app's webhook URL here. A UI does not need this endpoint.

## Endpoints

```http
GET /webhook/whatsapp
POST /webhook/whatsapp
```

## Verification handshake

Meta sends a `GET` request when you register the webhook URL. The endpoint echoes `hub.challenge` when `hub.verify_token` matches `WHATSAPP_WEBHOOK_VERIFY_TOKEN`, and returns `403` otherwise.

## Authentication

Meta signs every `POST` with the `x-hub-signature-256` header, an HMAC-SHA256 hex digest of the raw request body keyed by `WHATSAPP_APP_SECRET`.

## Event handling

`POST` receives inbound messages and delivery statuses. Every event is persisted to the WhatsApp message store. Inbound text messages are then matched to a request/supplier pair and resume the supervisor. A quoted reply resolves exactly through `channel_messages` (the quoted message ID names its thread). Anything else resolves through `channel_threads` on the sender's `waId`, where the most recently messaged thread wins.

## Responses

| Status | Body | Meaning |
| --- | --- | --- |
| 200 | `OK` | Event processed, including deliberately ignored events: statuses, unmapped `waId`, redelivery of an already-recorded message, or a non-text message. |
| 400 | `Malformed JSON` | The request body could not be parsed. |
| 401 | `Invalid signature` | The `x-hub-signature-256` header did not match. |
| 500 | (empty) | Persistence or agent dispatch failed. Meta redelivers with backoff. The last-message-ID dedupe keeps redeliveries from double-resuming the run, and a failed dispatch rolls that marker back so the retry is processed rather than skipped. |
| 503 | `{ "error": "WhatsApp channel is not configured" }` | The `WHATSAPP_*` variables are not set. |

## Failure behavior

The client refuses an outbound send while the 24-hour service window is explicitly closed, so that failure happens before Meta is called. Send failures that happen after Meta accepts a message, notably a first-touch text failing asynchronously (Meta error `131047`), arrive as status events and are recorded on the message. They never surface to the agent.
