waybill-arc is a procurement agent API built on Express and LangGraph. You send a free-text purchase request, and the system runs it through three autonomous stages (intake, search, and supervisor) to produce a structured part spec, collect supplier quotes, and recommend an award.

## How it works

A request flows through three stages, each backed by an LLM agent:

1. **Intake** resolves your free-text query into a structured part spec. If details are missing, it asks clarifying questions until the spec is complete.
2. **Search** selects internal suppliers from your supplier network and hands them off to the supervisor, which sends RFQs. In parallel, it can run an Exa web search for open-web suppliers.
3. **Supervisor** awaits supplier replies via webhook, qualifies incoming quotes, negotiates with counter-offers when needed, and produces a final award recommendation.
